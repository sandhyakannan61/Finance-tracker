💰 Finance Tracker

🚀 **Live Demo:** [Click here to open Finance Tracker](https://finance-tracker-jx2bv46szbaxsmadevmrw9.streamlit.app/)

A personal finance management application built using Python, Streamlit, SQLite and Plotly.

 Features
- User Authentication
- Income and Expense Tracking
- Transaction History
- Expense Categories
- Interactive Financial Charts

 Technologies Used
- Python
- Streamlit
- SQLite
- Plotly
